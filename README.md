##### **JSON Data Processor**



###### **Project Description**

The JSON Data Processor is a Python project that reads employee information from a JSON file and performs searching, filtering, and summary operations. It helps organize and process structured data efficiently.



###### **Objectives**

\- Learn how to handle JSON files using Python.

\- Search employee records by name.

\- Filter employees based on their department.

\- Calculate employee statistics and salary summaries.

\- Validate data and handle file errors.



###### **Technologies Used**

\- Programming Language: Python

\- Module: 'json'

\- File Format: JSON

###### 

###### **Features**

\- Load employee data from a JSON file.

\- Search employees by name.

\- Filter employees by department.

\- Display all employee records.

\- Calculate total employees, total salary, average salary, and highest salary.

\- Validate required keys in employee records.

\- Handle missing files and invalid JSON formats.

\- Save processed data to a new JSON file.



###### **Project Files**

\- json\_data\_processor.py – Main Python program.

\- employees.json – Sample employee data.

\- processed\_employees.json – Output file created when data is saved.

\- README.md – Project documentation.



###### **How to Run**

1\. Install Python on your system.

2\. Download or clone this repository.

3\. Keep `json\_data\_processor.py` and `employees.json` in the same folder.

4\. Open the terminal in that folder.

5\. Run the following command: python json\_data\_processor.py

6\. Select an option from the menu to search, filter, view summaries, or save data.
